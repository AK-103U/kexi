# 未决事项与迁移设想

这里保存原设计文档和探索笔记中的未完成问题、跨项目参考与可选方向。它们尚未成为本站约定；当前视觉基线见 [DESIGN](../../DESIGN.md)，当前开发机制见 [开发指南](../development.md)。

## 当前待处理的问题

- **Widget seed 旧字段**：`seed/seed.json` 的部分 widget 使用 `settings`，当前 EmDash 选项字段是 `props`。原校验出现过 `settings: not applied; widget options belong in "props"`。需要确认相关 widget 是否仍在使用，再更新 seed 并验证；修改文件不会自动修复现有库。
- **SQLite 原始持锁者（旧线路）**：迁移到 Cloudflare 前在 Node + SQLite 下复现了写锁导致保存失败，但首次事故的持锁进程尚未定位。当前部署使用 D1，不再有本地 SQLite 写锁；此条仅作历史记录，证据和复现方式见 [探索笔记](../../NOTES.md#sqlite-写锁与保存失败旧-node-线路)。
- **字典完整性检查**：当前中文 key 类型不能保证英文字典完整。是否增加专门检查，可在下一次国际化改动时评估；目前按 [验证指南](../verification.md#国际化字典) 核对。

## 视觉实验

字体候选包括 Geist、IBM Plex Sans、Söhne，以及 Source Serif、Crimson Pro、Lora 等。若评估衬线正文，可将 `1.0625rem` 正文字号和降低标题字重作为实验起点。这些建议尚未替代 Public Sans 基线，字体加载与授权需要另行核对。

## 产品与部署方向

- **发布为 GitHub 模板**：需要处理初始化路径与可移植性，并验证从空目录安装和构建；数学插件已是 npm 依赖，不再是本地路径障碍。
- **原创内容模型**：可以评估新增集合、字段或自定义正文块；自定义块的管理端注册与插件能力需核对当前 EmDash 版本。
- **第三语言**：除了语言配置、字典和内容行，还需要核对署名、菜单与回退。当前语言切换器按语言列表循环，是否改为直接选择需要产品决定。

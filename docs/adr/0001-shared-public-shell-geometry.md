# 公开页面共享布局几何

公开页面由 `Base.astro` 统一分配左栏、正文和右栏，页面组件只处理自身内容。在桌面三栏布局中，非文章页也保留空右栏轨道，使正文列在不同页面间保持相同位置。左栏固定在视口内，使用网格占位保持正文与右栏列位置不变；长菜单在左栏内部滚动。滚动条槽位保持稳定，避免滚动和客户端导航时横向跳动。这个决定接受桌面非文章页的空白空间，以换取跨页面一致的阅读位置；调整几何时需要同时验证不同页面、断点和滚动状态。

原先随窄视口依次隐藏左右栏的响应式行为，已由 [ADR 0005](./0005-single-rail-public-shell.md) 部分替代：右栏仍在 `1200px` 以下隐藏，左栏改为始终保留并在窄屏转为顶部横栏。

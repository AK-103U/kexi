# 公开页面使用单份左栏外壳

公开页面不再渲染独立页头；身份、导航、搜索、语言与主题控件共用 `Base.astro` 中唯一一份左栏标记。桌面侧栏借鉴 Tania Rascia 的分组方式：身份与外观控件位于顶部区，主导航使用左对齐的整行点击区域，搜索作为底部工具；管理员入口留在导航组的次级位置。当前态以浅底色和品牌文字区分，侧栏通过细边线与正文分隔。

视口小于 `1000px` 时，同一左栏改为贴顶横栏：品牌、搜索输入框、语言/主题控件与汉堡同排，菜单从栏下方展开为覆盖剩余视口高度的面板；视口不大于 `360px` 时只收起较长的站名，保留头像作为品牌标记。汉堡状态由左栏统一持有，并同步到 `aria-expanded`、按钮名称和菜单可见性。桌面搜索入口常驻显示输入框与占位文案，与主导航共享左对齐起点；⌘K / Ctrl+K 作为全局快捷键聚焦搜索框，不替代可见输入框。

搜索结果需要宽于 `200px` 左栏，因此左栏及其祖先不得裁切溢出内容；结果面板必须能覆盖相邻正文。保留单份 DOM 可避免隐藏副本引起的焦点、状态和脚本选择问题。共享网格、正文宽度与右栏轨道继续遵循 [ADR 0001](./0001-shared-public-shell-geometry.md)，本决定不改变正文或文章目录栏几何。

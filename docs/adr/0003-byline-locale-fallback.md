# 署名按内容语言回退

EmDash 的署名（byline）是行级多语言模型（migration 040）：每条署名按语言各存一行，共用 `translation_group`；内容行上的 credit 只记录 `translation_group`。渲染时按内容行语言严格匹配，当前语言没有对应署名行就整条丢弃，没有读取回退。署名区块因此会随语言消失——人名是专有名词，不该因为页面语言而消失。

Kexi 在主题层补回退：内容行语言不是默认语言时，若当前语言查不到署名行，就用默认语言的署名行补齐 `displayName` 和头像。`roleLabel` 保持当前语言内容行上的值（它随内容行存储，本来就分语言）。只补人名和头像，不补 `bio` 与自定义字段——它们确实随语言变化，缺失应由编辑补语言行。默认语言下保持 EmDash 原生行为，不做额外查询。

回退逻辑集中在 `src/utils/bylines.ts`，由首页、文章列表、文章详情页和分类／标签归档页调用（归档页同样渲染带署名的卡片）。EmDash 的仓库注释说明严格匹配是为避免在翻译页面显示错误语言的简介，并明确「想要回退的调用方自己实现」，所以这是被认可的扩展点。这个选择接受与 EmDash 严格模型的一处分歧，换取署名在所有语言下稳定显示；若 EmDash 后续提供内置回退选项，应改为使用官方接口。
